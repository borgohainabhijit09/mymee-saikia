# Mymee Saikia - Medical Travel Companion & Patient Support

Personal assistance for patients and families travelling outside Assam for medical treatment — from planning journeys and booking hospital-side stays to coordinating appointments, discharge, and the return home.

## Overview
A dedicated static web application designed with a mobile-first philosophy and a clean, responsive desktop layout.

- **Location**: Based in Morigaon, Assam
- **Destinations Supported**: Delhi NCR, Chennai, CMC Vellore, Bangalore, Mumbai, Hyderabad, Kolkata
- **Languages**: Assamese, Hindi, Bengali, English

## Features
- **Responsive Layout**: Fluid design optimized for mobile phones, tablets, laptops, and large desktop monitors.
- **Direct WhatsApp & Phone Integration**: Single-tap connection for patients and families.
- **Interactive Quick Enquiry Form**: Automatically pre-fills WhatsApp messages with patient requirements.
- **Transparent Pricing**: Detailed consultation fee breakdown and expense handling policies.
